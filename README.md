# Quad Timer

時間を測りたいとき、これ1つ。

キッチンタイマー、ストップウォッチ、ポモドーロ、カスタムの4種類を、1つのアプリで切り替えて使うフロントエンドです。

## 概要

- ホームでモードを選び、各画面でタイマーを操作する
- 4モードは同時に走らせない（排他）。切替時は確認ダイアログを出す
- いま実装済みの本体はキッチンタイマー。ほか3モードは画面枠と切替フラグのみ
- UI はダーク基調（ライム見出し、紫ボタン、黄アクセント）
- ブラウザで動く。ネイティブ包装（Capacitor / Electron）と OS 通知は後段

## 要件定義

### 目的

日常の「あと何分」「今から何分後」「作業と休憩」「経過時間」を、別アプリに散らさず扱う。

### 共通ルール

| 項目 | 内容 |
| --- | --- |
| モード | キッチン / ストップウォッチ / ポモドーロ / カスタム。同時走行はしない |
| 切替 | 走行中に別モードへ行くと確認。「YES」なら走行中のタイマーを全部無効にする |
| 例外 | ホームから、走っているキッチンへ戻るときは確認なし |
| 時刻 | 表示・判定の本体は `Date.now()`（端末時計） |
| 終了後 | 方針は OS 通知の予約。アプリを閉じてもキャンセルしない（未実装） |
| 言語 | OS 言語。`ja` 以外は英語。アプリ内の言語切替は持たない |
| 英語名 | キッチン相当は **Timer**（Kitchen Timer ではない） |
| 音 | アプリ内再生。iPhone のサイレントスイッチはアプリでは越えられない |

### キッチンタイマー（実装済み）

iPhone のタイマーに近い、複数本のカウントダウン。

- 同時最大 10 本。1 本あたり最大 24 時間。走行中の追加可
- 名前は付けない
- 時・分・秒はドラムロール（キーボード入力なし）
- 使用履歴（最近使った時間）最大 10 件。同じ時間は先頭に寄せる
- 走行中は一時停止 / 再開
- 終了後は合成アラームがループ。停止で音を止め、その 1 本を閉じる
- 直近の終了時刻を「xx:xxにアラームが鳴ります」と表示
- アラーム音: ピープ / ベル / 二音（Web Audio 合成）
- 音量スライダー。選択と音量は localStorage に保存

### ストップウォッチ（仕様。未実装）

- 上限 99 時間、ラップ 99
- 開始時刻を保存し、アプリ復帰時に経過を復元する（方針）

### ポモドーロ（仕様。未実装）

- 作業 25 分・小休憩 5 分は固定
- 長休憩は既定 30 分、最大 60 分
- 作業 4 回のあと長休憩。セット数は開始時に指定（既定 1、最大 8）
- 総時間は 24 時間以内。確認なしで自動進行

### カスタムタイマー（仕様。未実装）

- 「今から○分後」のアラームを複数本、一斉スタート（加算ではない）
- 1 セット最大 10 本。保存セット最大 10
- 走行中の 1 本追加はしない（それはキッチンの役割）
- 各行もセットの最遅も、開始から 24 時間以内

### 非機能

- React などの UI フレームワークは使わない
- 依存は開発用の Vite / TypeScript のみ（ランタイムライブラリなし）
- 状態の永続化は `localStorage`
- 署名・ストア配布・Xcode 設定は対象外

## 技術スタック

| 層 | 採用 |
| --- | --- |
| 言語 | TypeScript（ES2023、DOM） |
| マークアップ / スタイル | HTML + CSS（CSS 変数） |
| バンドル / 開発サーバ | Vite 8 |
| 状態 | モジュール内メモリ + 購読。画面は自前の描画関数 |
| 永続化 | `localStorage` |
| アラーム | Web Audio API（Oscillator + Gain） |
| 国際化 | `src/i18n/` の辞書。キーの正本は日本語 |

想定する後段（未導入）:

- Capacitor … モバイル包装と OS 通知
- Electron … デスクトップ包装

Node.js は開発機で Vite を動かすためだけに使う。Docker は不要。

## 永続化キー

| キー | 内容 |
| --- | --- |
| `quad-timer.kitchen.v1` | 走行中タイマー、使用履歴、下書きの時分秒 |
| `quad-timer.alarm.v2` | アラーム音種と音量（0〜1、既定 0.7） |

旧キー `quad-timer.sound.v1`（音種のみの文字列）は読み取り時に引き継ぐ。

## ディレクトリ

```
src/
  app.ts              画面の付け替え
  app-nav.ts          モード切替と確認ダイアログ
  audio/alarm.ts      合成音・音量
  domain/             上限・時計・キッチンの純ロジック
  i18n/               ja / en
  persist/storage.ts  localStorage の JSON 読み書き
  store/              アプリ全体とキッチンの状態
  styles/             トークンとレイアウト
  ui/                 各画面・ドラムロール・ダイアログ
```

タイマーの判定ロジックは `domain/`、DOM と副作用は `ui/` と `store/` に分ける。

## 開発

必要: Node.js（開発サーバ起動用）

```bash
npm install
npm run dev
```

既定は [http://localhost:5173/](http://localhost:5173/)。ポートが使われていれば Vite が次の空きポートを使う。

```bash
npm run build    # tsc && vite build
npm run preview  # 本番ビルドの確認
```
